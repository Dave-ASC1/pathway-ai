# Pathway AI: AI Prompts Used

This document records the major AI prompts used during planning, design, implementation, debugging, and documentation for the Pathway AI MVP.

## Project Understanding

1. "Go over each project file and figure out what I am working on and what is left to do. Use the project brief for more information on what I am trying to accomplish."
2. "Review the full-stack project handoff and summarize the intended technology stack, target users, MVP modules, and remaining implementation gaps."
3. "Compare the current project against the assignment requirements and explain whether it meets the criteria or needs more work."

## UI and Branding

4. "Restore the Pathway AI logo so the first three dots are hollow and the fourth dot is solid in a light blue hue."
5. "Create a loading state based on the logo where each circle drops into a diagonal stair formation."
6. "Slow the loader slightly and preserve the icon color and line style."
7. "Revamp and beautify the landing page while keeping the student career readiness goal at the core."
8. "Apply Apple-style typography using SF Pro Display-style headers and SF Pro Text-style body copy."

## Product Scope

9. "What is going well in the browser, what still needs work, and what recommendations would improve the app based on the project scope?"
10. "Identify the next practical build step that makes the project stronger for the assignment."
11. "Proceed to build the dashboard plus resume checker MVP, then package documentation and the GitHub repo around it."

## Implementation

12. "Create a dashboard route that represents the logged-in Pathway AI workspace and links to the core modules."
13. "Create a resume checker MVP that runs locally without API keys and compares resume text to a target job description."
14. "Generate deterministic resume feedback with match score, matched keywords, missing keywords, section checks, strengths, and recommended improvements."
15. "Update the landing page calls to action so users can enter the dashboard and working resume checker."

## Verification and Packaging

16. "Run lint and production build to confirm the implementation works."
17. "Create documentation for Functional Decomposition Level 0 and Level 1, technical design flow, and user operational flow."
18. "Create updated Gantt chart, Critical Path Analysis, and PERT chart for the current MVP."
19. "Update README so the project can run on a separate computer without the developer's help."
